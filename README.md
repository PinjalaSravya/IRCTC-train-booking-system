# IRCTC-train-booking-system
IRCTC Train Booking System
This project is a web-based Train Ticket Booking System inspired by IRCTC. It allows users to register, login, search for trains, and book tickets for multiple passengers using a database-driven approach.
 Features
•	 User Registration & Login 
•	 Search trains (Source → Destination) 
•	 Display available trains 
•	 Seat selection (SL, 3A, 2A, 1A) 
•	 Multiple passenger booking 
•	 Store booking details in database 
•	 Booking confirmation 

 Tech Stack
•	Frontend: HTML, CSS, JavaScript 
•	Backend: Python (Flask) 
•	Database: MySQL (XAMPP)
